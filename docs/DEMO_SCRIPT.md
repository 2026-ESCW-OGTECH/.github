# 3분 데모 스크립트

데모 영상은 스크린샷만이 아니라 실제 임베디드 시스템을 보여줘야 합니다.

## 목표 실행 시간

- 최대 길이: 3분.
- 최소 품질: 720p.
- 실제 구급함, 터치스크린, LED, 센서/카메라 동작, 안전 대체 경로를 보여줘야 합니다.

## 스토리보드

| 시간 | 장면 | 메시지 |
| --- | --- | --- |
| 0:00 ~ 0:20 | 완성된 구급함 보여주기 | 캠핑 및 재난 상황을 위한 오프라인 스마트 구급함 |
| 0:20 ~ 0:45 | 터치 시나리오 선택 | 인터넷이나 앱 설치 없이 사용자가 조작할 수 있음 |
| 0:45 ~ 1:10 | LED 서랍 안내 | 실제 구급함에서 올바른 물품 위치가 켜짐 |
| 1:10 ~ 1:35 | 음성 또는 텍스트 분류 | 로컬 분류기가 시나리오를 선택하지만 의료 지침은 생성하지 않음 |
| 1:35 ~ 1:55 | CO 센서 위험 흐름 | 센서 입력이 응급 안내를 트리거함 |
| 1:55 ~ 2:15 | ESP32 카메라 업로드 | 카메라 노드가 사진을 보내고 Pi가 보수적인 시각 플래그를 제공함 |
| 2:15 ~ 2:40 | 119 및 CPR 지원 | 응급 경로와 메트로놈을 사용할 수 있음 |
| 2:40 ~ 3:00 | 신뢰성 마무리 | 오프라인 대체 경로, 고정 카드, 공개 GitHub 준비 상태 |

## 필수 촬영 장면

- 전체 구급함 와이드 샷.
- 라벨이 붙은 서랍과 LED 클로즈업.
- 터치스크린 상호작용.
- 센서/카메라 하드웨어 샷.
- 실패 장면을 편집으로 숨기지 않는 하나의 연속 흐름.
- 프로젝트 이름과 GitHub 자리표시자가 보이는 마지막 장면.
